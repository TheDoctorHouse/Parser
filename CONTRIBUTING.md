# Contributing

Contributions are welcome.

## Getting started

1. Fork the repository.
2. Create a branch from `main`.
3. Make your changes.
4. Build and run the tests.
5. Open a pull request.

## Issues

Feel free to open an issue for bugs, feature suggestions, or questions.

For larger language changes, consider opening an issue before implementation
so the syntax and behavior can be discussed first.

## Pull requests

Keep pull requests focused on a single change where practical.

Include tests for bug fixes and new language behavior when applicable.
