A parser and interpreter written in C#.

Usage:
parser <command> [--stacktrace]

Commands:
help      Display help information about a command.
run       Run the lexer, parser, and interpreter on a file.
lex       Run lexer on the specified file, outputing tokens.
lex-code  Output tokens of the provided code.
ast       Run lexer and parser on the specified file, outputing AST.
ast-code  Output an abstract syntax tree representation of the provided code.

Run 'parser help <command>' for more information about a command.
